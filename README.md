# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a desktop-based application developed using Python to help users manage, monitor, and analyze their daily expenses.

## Technologies Used
- Python
- CustomTkinter
- SQLite
- Pandas
- Matplotlib

## Key Features
- Add and manage expenses
- Track daily spending
- Store transactions in SQLite
- Visualize expenses through charts
- Analyze spending patterns

## Project Objective
The main objective is to provide users with a simple and efficient way to manage their personal finances.
